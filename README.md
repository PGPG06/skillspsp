# skillspsps

Raccolta personale di skill di design frontend per agenti AI (Claude Code, Claude, Cursor, ecc.).

- `impeccable/` — Impeccable v4.5.0 di Paul Bakaus (Apache 2.0): https://impeccable.style · https://github.com/pbakaus/impeccable
- `design-taste-frontend/` — Taste Skill v2 di Leon Lin e blueemi: https://www.tasteskill.dev · https://github.com/Leonxlnx/taste-skill

Ogni cartella contiene la licenza del progetto originale. I diritti restano agli autori.

## Come usarle

Copia la cartella della skill in `~/.claude/skills/` (tutte le sessioni) oppure in `.claude/skills/` dentro il progetto, poi riavvia lo strumento.
